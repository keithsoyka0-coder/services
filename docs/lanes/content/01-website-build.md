# Standard 4-page site

**$2,900**

A from-scratch website that tells people what you sell, explains how you can help, and gives them a clear way to contact you. The plan, design, and handoff are part of the work—not details you have to reconstruct later.

## What you walk away with

Four defined pages: landing, contact, about, and terms/privacy. You receive the site and the documentation needed to understand its structure, run it, and hand it to another maintainer.

## What's included

- The standard four-page build: landing, contact, about, terms/privacy.
- Separate implementation and design specifications. The design includes a theme package: global tokens, color scheme, and branding breakdown. Client-facing specifications arrive as styled PDFs.
- Page contracts explaining each page's purpose, connections, flow, and intended behavior.
- Documented build, test, and deployment scripts and a Dockerized build for portability.
- README, quickstart, CurrentState, manifest, index, handoff guide, and troubleshooting document.
- Workflows and skills tailored to the agreed stack; API flow documentation if APIs are involved.
- File-level provenance and a test suite run green before handoff.

## What's not included

Digital Intelligence (DI) integration is not part of this offer. Logo / branding and ongoing maintenance are separately scoped add-ons. The four-page price is not an unlimited-page or unlimited-feature package; changes beyond the agreed scope need a separate agreement.

Hosting is a choice to be compared, not a single bundled platform promise. Hosting arrangements and costs are confirmed in scope. The terms/privacy page is part of the four-page structure; the content responsibilities for it must be agreed before the build.
