# Codebase / website audit + refresh

**scoped**

Not every venture starts from zero. Begin with the code or website you already have, and define what needs attention before committing to a refresh.

**Primary action: Request a free consultation** → `/#consultation`

## What you walk away with

An audit-and-refresh engagement scoped to the existing system. The work, findings format, refresh boundaries, and price are defined before you commit—not inferred from the size of the repository or the offer name.

## What's included

- A scoped engagement focused on an existing codebase or website.
- An explicit agreement on the audit work and any refresh work to be delivered.
- For software build work included in the refresh: documented scripts; a Dockerized build for portability; README, quickstart, CurrentState, manifest, index, handoff, and troubleshooting documentation for the delivered work.
- For that build work: stack-specific workflows and skills, file-level provenance, tests run green before handoff, page contracts where pages are involved, and API and Digital Intelligence (DI) flow documentation where applicable. A Digital Intelligence (DI) integration includes its maintenance collaborator alongside the system component.

## What's not included

The offer does not mean every issue in an existing system will be fixed for one unspecified fee. An automatic full rebuild, unlimited changes, and ongoing maintenance are not promised. The agreed scope determines which refresh work is included.

An audit alone does not include the build care package or a promise to rewrite the existing repository. Any new work beyond the agreed audit/refresh scope needs a separate agreement.

## Start with the system you have

**Free consultation — $0:** explain what exists and what you want to change. We establish fit; no free specification work or free design is included.

**Discovery (scoped, paid) — $600:** when a separate planning engagement is needed, it gathers goals, constraints, and specifications and presents a route forward. Credited toward build on acceptance. It is not automatically credited toward an audit.

### Do I need to replace my existing site?

A replacement is not assumed by this offer. The engagement starts from the existing codebase or website and the scope you agree to address.

### Is there a fixed public price?

The price is scoped. The audit and refresh boundaries need to be defined before a price can be agreed.
