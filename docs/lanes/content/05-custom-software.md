# Custom software (small tool, fixed scope)

**$8,500–$10,000**

A small software tool built around a defined job. Agree what it needs to do, see the plan and design, and receive the code with a documented path to running and maintaining it.

**Primary action: Request a free consultation** → `/#consultation`

## What you walk away with

The small tool defined in your agreed scope, with implementation and design specifications, tested delivery, and a handoff that another maintainer can understand.

## What's included

- A fixed-scope small-tool build. The functionality and acceptance criteria are agreed before implementation.
- Separate implementation and design specifications, delivered as styled client-facing PDFs. The design includes the applicable theme package: global tokens, color scheme, and branding breakdown.
- Documented build, test, and deployment scripts and a Dockerized build for portability.
- README, quickstart, CurrentState, manifest, index, handoff guide, and troubleshooting document.
- Workflows and skills tailored to the agreed stack and services.
- API flow documentation when the tool touches APIs; Digital Intelligence (DI) flow documentation when it integrates DI. Where DI is integrated, the system component is accompanied by a maintenance collaborator.
- Page contracts for any pages in scope, file-level provenance, and tests run green before handoff.

## What's not included

This is a small tool, not an open-ended product-development engagement. The price range does not promise unlimited features, integrations, or revisions. The final scope and fee within the range are agreed before work begins.

Ongoing maintenance, work beyond the baseline workflows and skills, and logo / branding are separately scoped add-ons. Hosting options and any external service costs need to be settled in the project scope rather than assumed to be bundled.

## Plan before implementation

**Free consultation — $0:** explain the job the tool needs to do; we check fit. The conversation does not include free specification work or free design.

**Discovery (scoped, paid) — $600:** gather goals, constraints, and specifications and present the route forward. Credited toward build on acceptance. Implementation and design remain separate specifications, so scope and interface decisions are visible before the build.

No. The repository, scripts, Dockerized build, and documentation are intended to support a handoff. Maintenance by me is separately scoped.
